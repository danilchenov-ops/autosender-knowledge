# Посевы Telega.in (TG/MAX-каналы)

Кабинет: telega.in, логин danilchenov (заказчик ООО «ТД ЗИВЕРД»). Доступ Claude — через Chrome-расширение
на залогиненной вкладке. API нет; данные снимаются со страниц /orders/order_channels?id=<pid> и
модалки «Смотреть статистику» (endpoint /orders/order_channels/<ocid>/analytic, один XHR на загрузку страницы —
второй виснет, поэтому перед каждым запросом перезагружать страницу).

## Решения / что делать

1. Новых размещений без трекинга не делать.
2. Deeplink в ботов (`?start=tg_<slug>_<date>`), payload → поле utm_source лида. Для сайта — прокладка
   mes.autosender.ru с utm_source=telega.
3. Отказ от «Сани во Флориде» и инвест-каналов до доказательств.
4. Тест после трекинга: 5–7 дешёвых региональных MAX 1/24 ≤100 тыс./волна; приоритет — регионы ДВ
   (Артём/Владивосток/Якутск/Хабаровск/Сахалин — лучшая конверсия в оплату по Метрике).

## Контур учёта (с 07.09.2026) — KPI: цена подписчика

Решения Тимофея 07.09: экономика посевов считается **только по цене подписчика**; порог **300 ₽**;
волна ≤100 тыс. ₽ на 5–8 каналов; CTA постов — «подпишись на канал» (не калькулятор);
MAX — прямая ссылка на канал, подписки с Директа вычитаются.

- Миграция `app/sql/027_telega.sql`: таблица `telega_placements`, вью `v_telega_econ`.
- Скрипт `app/telega.py` (в контейнере ropbot-tgbot-1):
  `link <slug> [date]` — именованная ссылка TG `seed_<slug>_<date>` (в `tg_invite_links`, campaign=`telega_<slug>`);
  `add tg|max <slug> <price> '<YYYY-MM-DD HH:MM>' [ocid] [name] [fmt] [views]`; `views <ocid> <n>`; `report`.
- Подписчики TG = вступления по ссылке размещения − выходы в окне (48 ч по умолчанию).
- Подписчики MAX = Δ`max_channel_counts` за окно − вступления с привязкой к Директу (exact/campaign)
  − базовый органический прирост (среднее за 7 дней до поста). Счётчик пишется кроном каждые 5 мин
  круглосуточно, ночные посты считаются так же.
- Файлы скопированы в контейнер (`docker cp`); в образ ещё не собраны — при пересборке
  `docker compose build tgbot` подхватятся из `app/`.
- История до 07.09 (85 размещений) не восстанавливается: счётчики и ссылки появились 07.09.
