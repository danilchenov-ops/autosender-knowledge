# Реестр инфраструктуры Autosender

Единый источник правды по серверам, сервисам, интеграциям и принятым решениям.
Доступен из любого чата через `ropbot ssh_run`. Ведётся Claude и Тимофеем.

**Правило: прежде чем делать выводы о том, что настроено и работает — прочитай
нужный файл отсюда. После любого изменения — допиши в `changelog.md` и сделай
commit.**

## Файлы

| Файл | Что внутри |
|---|---|
| `servers.md` | Серверы, IP, доступ, что на каждом крутится |
| `services.md` | Сервисы: статус, порты, крон, логи, где код |
| `integrations.md` | Директ, Метрика, Битрикс24, телефония, Telegram, MAX |
| `changelog.md` | Журнал изменений за текущий месяц, только дописываем, с датой. Прошлые месяцы — `changelog-ГГГГ-ММ.md` |
| `decisions.md` | Принятые решения и обоснование |
| `open-questions.md` | Что висит нерешённым |
| `rules.md` | Правила ведения реестра — вставляются в инструкции каждого проекта |
| `errors.md` | Журнал ошибок анализа, общий |
| `projects/` | По одному файлу на направление: цель, сделано, осталось |
| `inbox/` | Сырые выгрузки чатов от Тимофея — Claude разбирает и чистит |
| `audit/` | Автоматические снимки фактического состояния (крон, 06:00); `kbcheck-latest.md` — еженедельная сверка реестра |

## Как читать и вести (с 08.09.2026)

1. В каждом `projects/*.md` первый раздел — `## СОСТОЯНИЕ НА <дата>`: актуальная
   картина. Читать его, потом хвост файла с этой даты, потом `changelog.md`.
   Всё между — история. Блок переписывается целиком на каждом чекпоинте.
2. Закрытый вопрос в `open-questions.md` не удаляется: под ним `→ ЗАКРЫТО дата: чем`.
3. `services.md` — крон сверяется с `audit/latest.md`; при расхождении верить аудиту.
4. Понедельник 09:00 `kbcheck.sh` шлёт Тимофею в бот: чьи «Состояния» протухли (>14 дн),
   что есть в кроне и нет в реестре, сколько вопросов открыто, что лежит в inbox,
   не разросся ли changelog. Ответ на него — команда Claude «сверь реестр».
5. Бэкап базы: `watch.sh` проверяет и возраст, и размер (>50 МБ); копия уходит
   на 195.2.74.207:/opt/backups/rop (14 штук).

## Принцип

- **Реестр** — что задумано и решено.
- **`audit/`** — что есть на самом деле, снимается автоматически.
- Расхождение между ними — сигнал, а не ошибка. Разбираем, обновляем реестр.
