# Реестр инфраструктуры Autosender

Единый источник правды по серверам, сервисам, интеграциям и принятым решениям.
Доступен из любого чата через `ropbot ssh_run`. Ведётся Claude и Тимофеем.

**Правило: прежде чем делать выводы о том, что настроено и работает — прочитай
нужный файл отсюда. После любого изменения — допиши в `changelog.md` и сделай
commit.**

## Файлы

| Файл | Что внутри |
|---|---|
| `servers.md` | Серверы, IP, доступ, что на каждом крутится |
| `services.md` | Сервисы: статус, порты, крон, логи, где код |
| `integrations.md` | Директ, Метрика, Битрикс24, телефония, Telegram, MAX |
| `changelog.md` | Журнал изменений, только дописываем, с датой |
| `decisions.md` | Принятые решения и обоснование |
| `open-questions.md` | Что висит нерешённым |
| `projects/` | По одному файлу на направление: цель, сделано, осталось |
| `inbox/` | Сырые выгрузки чатов от Тимофея — Claude разбирает и чистит |
| `audit/` | Автоматические снимки фактического состояния (крон, 06:00) |

## Принцип

- **Реестр** — что задумано и решено.
- **`audit/`** — что есть на самом деле, снимается автоматически.
- Расхождение между ними — сигнал, а не ошибка. Разбираем, обновляем реестр.

## Секреты

Паролей и токенов здесь НЕТ и быть не должно. Только указатели, где лежат.
